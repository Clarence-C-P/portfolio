# Portfolio

A personal portfolio website by **REN_DC.DEV** with a private resume editor. Visitors see my projects, skills and experience; I log in to manage my content, build tailored resume versions and export them on US Letter paper.

## Features
- **Public portfolio:** profile, skills, projects, experience and education
- **Private editor:** only the owner can log in to add, edit and delete content
- **Resume versions:** pick which items go into each resume (e.g. "Web Dev job", "Freelance client")
- **Templates:** single-column, with a two-column template coming next
- **Export:** Letter-size (8.5 × 11 in) preview, PDF export (Canva-ready), with DOCX export coming next

## Tech stack
- HTML, CSS and vanilla JavaScript (ES modules), with no framework and no build step
- [Supabase](https://supabase.com): Postgres database, authentication and file storage, protected by Row Level Security
- Browser print with CSS `@page` for PDF export
- [docx](https://docx.js.org) for Word export
- Hosted on GitHub Pages
